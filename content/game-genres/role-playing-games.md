# Role-Playing Games

Role-playing games, also called RPGs, usually focus on controlling a character and improving that character over time. Players might gain experience, unlock abilities, find better equipment, or make decisions that affect the story.

## Building a Character

One thing that makes RPGs interesting is progression. A character may start out weak but become much stronger as the game continues.

RPGs can also have large stories and worlds. Some games give players choices about how they want to complete missions or what type of character they want to build.

### Common RPG Features

1. Character upgrades
2. Different weapons or equipment
3. Quests
4. Experience points
5. Story choices

RPG elements have also started appearing in other types of games. Even games that are mainly action games sometimes include upgrades and skill trees.

[[popular-games/god-of-war|God of War]] has some RPG-style features because players can upgrade equipment and abilities, even though it is mainly an action game. This shows how game genres can sometimes overlap instead of fitting into only one category.
