# Gaming Monitors

A gaming monitor is the screen used to display a game. Monitors can look similar on the outside, but their performance can be very different.

## Refresh Rate

One of the biggest things gamers pay attention to is refresh rate. A higher refresh rate can make movement look smoother, especially in fast games like [[game-genres/first-person-shooters|first-person shooters]].

Resolution is also important because it affects how sharp the image looks.

### Things Gamers Look For

- Screen size
- Resolution
- Refresh rate
- Response time
- Display quality

The monitor also needs to match the power of the computer. A strong [[gaming-hardware/graphics-cards|graphics card]] can help produce high frame rates, but the monitor needs to be able to display them.

Some players care more about smooth gameplay while others care more about image quality.

I think monitors are easy to overlook because people usually talk more about the computer itself, but the monitor has a big effect on what the player actually sees.
