# Organizing System Analysis: Minecraft Wiki

I chose the Minecraft Wiki because I already know the game and I have used wiki pages before when I needed help with crafting, mobs, or items. The site has a lot of information, but it is still pretty easy to move around because everything is connected.

---

## 1. Resources Being Organized

The main resources on the Minecraft Wiki are pages about things in the game. This includes blocks, items, mobs, biomes, commands, updates, and different game versions. For example, there are pages for creepers, diamonds, the Nether, and different biomes.

The wiki also has images, tables, guides, and lists. A page about a mob might include its health, where it spawns, what it drops, and pictures of what it looks like. This makes the pages useful when someone wants a quick answer without having to search through a lot of other websites.

## 2. Main Interactions

The biggest interaction is searching for information. If I forget how to craft something or want to know where an item comes from, I can search for it and usually find a page right away.

People can also browse the site by clicking links. Some common things people might use the wiki for are:

- Looking up crafting information
- Learning about mobs
- Checking game updates
- Finding information about biomes
- Comparing different versions of Minecraft

I think this works well because Minecraft has so many items and features that it would be hard to remember everything.

## 3. Classification System

The Minecraft Wiki mainly uses categories and subcategories. This makes it a mix of a category system and a hierarchy. For example, there is a larger Minecraft category, and under it there are groups for things like blocks, items, gameplay, history, and versions. There are also more specific categories such as biomes and mobs.

This system works well for Minecraft because one page can fit into more than one group. A mob can be hostile, live in the Nether, and also belong to a certain game version.

## 4. Relationships Between Resources

The wiki connects pages mostly through links. When one page mentions another item, mob, place, or feature, that word can link directly to another page. The site also uses categories and navigation boxes to connect similar pages.

For example, someone reading about a biome can click links to mobs, blocks, or structures found there. A person could start by reading about the Nether and then move to pages about Nether mobs, blocks, or items.

Overall, I think the Minecraft Wiki is organized well because the pages are connected in a way that makes it easy to keep exploring without having to go back to the search bar every time.
